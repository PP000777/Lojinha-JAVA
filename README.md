# Lojinha em Java 🛒

Projeto simples feito para aprender Java.

O programa simula uma lojinha no terminal onde é possível:

- Cadastrar produtos
- Acessar menus
- Fazer compras
- Calcular o total

## Como executar?

### Crie uma pasta bin
Crie uma pasta com o nome "bin" para armazenar todos os arquivos .class que vai ser gerado, compilando todos os arquivos em um local para evitar bagunça nos arquivos

### Compilar
cd project
javac -d bin src/*.java src/functions/*.java

### Executar
java -cp bin mainLojinha
